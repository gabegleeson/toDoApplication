# To-Do Application

The project is a basic to-do app that keeps track of day to day things a user 
needs to complete. The app is for busy users who are on the go and need to keep
track of their daily errands. 

## Building and running

It can be built and run using javac and java.

## Usage

There is a login page where the user can login, signup or exit. Upon signup
the user is asked for their desired username and password. Upon login the user
is asked for a username and password which must match valid credentials.
After logging in the user can add an item, mark an item as done, mark an 
item as undone or delete an item.
